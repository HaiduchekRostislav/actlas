# Actlas – Actor Atlas

Лабораторна робота з дисципліни **"Поглиблене програмування на Java"**.

Actlas – це веб-застосунок для пошуку акторів за фільмами. Дозволяє знаходити інформацію про акторів, переглядати їх біографії українською мовою та відстежувати переглянуті фільми.

**Технологічний стек:** Java 17, Spring Boot 3, Spring Data JPA, H2, Thymeleaf, Jsoup, Jackson

Зовнішні джерела даних: [IMDb API](https://imdbapi.dev/) для отримання інформації про фільми та акторів, [Kinobaza](https://kinobaza.com.ua/) для парсингу описів українською мовою.

---

## Функціонал

- **Пошук фільмів** – динамічний пошук через IMDb API з підказками в реальному часі
- **Картка фільму** – постер, рейтинг, жанри, опис українською та англійською з перемикачем мови
- **Актори фільму** – список акторів з фото, датою народження та біографією українською
- **Історія переглядів** – збережені фільми з можливістю видалення
- **Фільми актора** – перегляд всіх збережених фільмів конкретного актора
- **Спільні фільми** – закріпи до 3 акторів і знайди фільми де вони знімались разом
